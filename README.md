# Awish Clinic - Premium Aesthetic, Skin & Hair Care

A highly polished, modern web application for **Awish Clinic** built with Next.js, TypeScript, and TailwindCSS, utilizing state-of-the-art visual symmetry, premium animations, and custom interactive components.

## ✨ High-End Redesign Features

### 1. 2-Column Editorial Hero & Floating Glass Form
Rebuilt the dynamic treatment page hero sections into custom, light-themed 2-column editorial layouts with high-end typography, hover scaling zoom transitions, and a **Floating Glass Booking Form** directly connected to appointment APIs.

### 2. Draggable Before/After Image Slider
Constructed an interactive, mobile-first draggable image comparison slider using pure React pointer events (zero dependencies, completely touch-responsive).

### 3. Symmetrical Pages & Balanced Grids
* **Clinic Environment (`/clinic`):** Houses detailed segments and an interactive **"Our Clinic Environment"** spaces gallery (Reception Lounges, Treatment Suites, Private Consulting Offices).
* **About Us (`/about`):** Tailored, vision-oriented history page with clean 3-column values grid and a balanced 2-column co-founders spotlight section.
* **Our Medical Team (`/team`):** Symmetrical doctor profiles utilizing balanced 2-column grids (`sm:grid-cols-2`) for MBBS, MD clinical co-founders, resolving visual column spacing issues.
* **Services Directory (`/services`):** Symmetrical services index with perfect text-height alignments across all columns using advanced Flexbox constraints.

### 4. Majestic Footer & Vector SVG Social Icons
Overhauled the global footer directory into a perfectly balanced, symmetrical 4-column layout with centered Specialized Concern Clouds, hover sliding indicators, and vector SVG stroke logos for Instagram, Facebook, and YouTube.

---

## 🛠️ Technology Stack

* **Framework:** Next.js (App Router, Turbopack compiler)
* **Language:** TypeScript
* **Styling:** Vanilla CSS, TailwindCSS
* **Features:** React Pointer Events, Custom CSS Bezier Curves (`cubic-bezier(0.16, 1, 0.3, 1)`), Responsive Grids

## 🚀 Getting Started

### Prerequisites
Make sure you have Node.js (v18+) and npm installed.

### Installation
1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Build the production package:
   ```bash
   npm run build
   ```

4. Start the production server:
   ```bash
   npm run start
   ```
